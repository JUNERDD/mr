# Agent Instructions

- Before changing behavior, command semantics, workflow logic, branch strategy, user-facing output, or configuration, identify whether `README.md` needs to be updated.
- After any logic change, explicitly decide one of:
  - update `README.md` in the same change; or
  - leave `README.md` unchanged because the change is internal-only, and mention that decision in the final response.
- Keep README examples, behavior bullets, and Mermaid branch-flow diagrams aligned with implemented behavior.
